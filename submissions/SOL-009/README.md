# SOL-009 채점 기록

## 결과

통과

## 충족한 요구사항

- `DuelState` enum으로 `None → Open → Active → Finished` 상태 표현
- `Duel` struct와 mapping으로 결투별 데이터 관리
- 필드 이름 방식으로 새 결투 생성
- 지역 `storage` 참조를 통한 상태 변경
- 생성자의 자기 결투 참가 방지
- 활성 상태와 피해량 범위 검사
- 생성자와 상대만 공격 가능
- 치명타 시 체력을 0으로 고정해 언더플로 방지
- 결투 종료 시 상태를 실제로 `Finished`로 변경
- 공격당 `AttackResolved` 이벤트를 정확히 한 번 발생

## 수정 사항

초기 제출의 `hp -= damage`는 남은 체력보다 피해량이 크면 Solidity 0.8의 산술 검사로 revert될 수 있었다. 감소 전에 `damage >= hp`를 비교하고, 치명타이면 체력을 0으로 설정하도록 수정했다.

상태 변경에 비교 연산자 `==`가 사용되어 실제 상태가 바뀌지 않던 부분을 대입 연산자 `=`로 바로잡았다. 또한 치명타에서 `Finished` 이벤트를 발생시킨 뒤 `Active` 이벤트까지 중복 발생하던 흐름을 하나의 공통 이벤트 발생 지점으로 합쳤다.
