Foundry + AnvilERC-4337 UserOperation

스마트 계정에서 게임 동작 실행하기

로컬 Anvil 체인에 EntryPoint, Factory, Counter를 배포하고, MiniAccount가 서명된 UserOperation으로 Counter를 올리는 과정을 화면에서 확인합니다.

로컬 연습 전용: Anvil이 출력한 테스트용 private key만 입력하세요. 실제 지갑 키를 입력하지 마세요. 이 페이지는 입력값을 저장하거나 외부 서버로 보내지 않고, RPC 요청은 로컬 Anvil로만 전송합니다.

1. 로컬 연결 및 배포

Anvil을 먼저 실행한 뒤 테스트 키를 입력하세요.

배포 주소

네트워크- 소유자- EntryPoint- Factory- 게임 Counter- 예측된 MiniAccount아직 계산 전

2. UserOperation 실행

버튼을 누르면 예측 주소에 로컬 테스트 ETH를 넣고, UserOperation을 서명해 EntryPoint에 제출합니다.

Counter: - 계정 배포: -
먼저 컨트랙트를 배포하세요.

실행 순서

  1. Factory가 owner와 salt로 스마트 계정 주소를 예측합니다.
  2. EntryPoint가 initCode를 통해 Factory에 계정 생성을 요청합니다.
  3. MiniAccount가 UserOperation 서명을 검사하고 가스비를 EntryPoint에 보냅니다.
  4. EntryPoint가 MiniAccount.execute를 통해 Counter.increment를 호출합니다.
  5. 화면에서 계정 배포 여부와 Counter 값이 0에서 1로 변했는지 확인합니다.

이 데모는 로컬 체인의 상태만 바꿉니다. 실제 네트워크 배포나 실제 ETH 결제는 발생하지 않습니다.
