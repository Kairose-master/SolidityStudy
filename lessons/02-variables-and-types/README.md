# 2강 — 변수와 자료형

## 학습 목표

- 상태 변수, 지역 변수와 전역 변수 구분
- 값 타입과 참조 타입 구분
- 정수, 논리형, 주소, 고정 크기 바이트와 문자열 사용
- 상태 변수 가시성 이해
- 기본값, 오버플로와 온체인 데이터 공개성 이해

## 핵심 내용

Solidity는 정적 타입 언어이므로 모든 변수에 자료형을 지정한다.

변수는 저장 위치에 따라 상태 변수, 지역 변수, 전역 변수로 나뉜다. 자료형은 값 자체가 복사되는 값 타입과 데이터 위치를 함께 고려해야 하는 참조 타입으로 나뉜다.

대표적인 값 타입은 다음과 같다.

- `uint8`부터 `uint256`: 부호 없는 정수
- `int8`부터 `int256`: 부호 있는 정수
- `bool`: `true` 또는 `false`
- `address`, `address payable`: 20바이트 이더리움 주소
- `bytes1`부터 `bytes32`: 고정 크기 바이트

`uint`와 `int`는 각각 `uint256`, `int256`의 별칭이다. Solidity 0.8 이상에서는 일반 산술의 오버플로와 언더플로가 기본적으로 트랜잭션을 되돌린다. 지수 연산자는 `**`이며 `^`는 XOR 연산자다.

`string`, 동적 `bytes`, 배열, 구조체와 매핑은 참조 타입이다. 함수에서 참조 타입을 사용할 때는 `memory`, `calldata`, `storage` 같은 데이터 위치가 중요하지만 자세한 동작은 이후 강의에서 다룬다.

상태 변수에는 `public`, `internal`, `private`를 사용할 수 있다. `external`은 상태 변수 가시성으로 사용할 수 없다. `private`과 `internal`은 다른 컨트랙트의 직접 접근을 제한할 뿐, 블록체인에 기록된 데이터를 비밀로 만들지 않는다.

## 연습문제 SOL-002 — 안전한 게임 설정

`GameConfig.sol`에 `GameConfig` 컨트랙트를 작성한다. 함수, 생성자, 상속과 `import`는 사용하지 않는다.

다음 상태 변수를 정확한 이름, 타입, 가시성 및 초깃값으로 선언한다.

| 변수 | 타입 | 가시성 | 초깃값 |
|---|---|---|---|
| `gameName` | `string` | `public` | `"Audit Arena"` |
| `maxPlayers` | `uint8` | `public` | `200` |
| `startingGold` | `uint16` | `internal` | `10_000` |
| `seasonScore` | `int32` | `private` | `-250` |
| `paused` | `bool` | `public` | `false` |
| `admin` | `address` | `public` | `msg.sender` |
| `rulesetId` | `bytes32` | `private` | `"RULESET_V1"` |

추가 조건:

1. SPDX 라이선스는 MIT로 한다.
2. 컴파일러 범위는 `^0.8.24`로 한다.
3. 상태 변수 선언 순서는 표와 같아야 한다.
4. 함수, 생성자, 상속과 `import`는 추가하지 않는다.
