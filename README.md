# SolidityStudy

Solidity 기초부터 스마트 컨트랙트 보안까지 단계적으로 학습하는 저장소입니다.

각 강의는 다음 항목을 포함합니다.

- 핵심 개념과 코드 설명
- 직접 제작한 연습문제
- 학습자 제출 코드
- 요구사항 및 보안 관점의 채점 기록

## 진행 현황

| 강의 | 주제 | 문제 | 결과 |
|---|---|---|---|
| 1강 | 컨트랙트 선언과 `pragma` | SOL-001 두 번의 인사 | 통과 |
| 2강 | 변수와 자료형 | SOL-002 안전한 게임 설정 | 통과 |
| 3강 | 함수 기초와 상태 변경 | SOL-003 전투 피해 계산기 | 통과 |
| 4강 | `view`, `pure`, `payable`와 제어문 | SOL-004 아레나 금고 | 통과 |
| 5강 | `mapping`과 주소별 상태 | SOL-005 플레이어 레지스트리 | 통과 |
| 6강 | `require`, `revert`, `assert` 예외 처리 | SOL-006 안전한 훈련소 | 통과 |
| 7강 | 이벤트와 로그 | SOL-007 아레나 경기 기록소 | 통과 |
| 8강 | 배열과 데이터 위치 | SOL-008 훈련 점수 기록부 | 통과 |
| 9강 | 구조체와 열거형 | SOL-009 미니 결투 상태 머신 | 통과 |
| 10강 | 접근 제어와 `modifier` | SOL-010 아레나 운영 권한 | 수정 후 통과 |
| 11강 | 턴 기반 상태 머신과 불변식 | SOL-011 교대 결투 | 과제 대기 |

## 디렉터리

```text
lessons/       강의 브리프와 문제
submissions/   통과한 제출 코드
```

전체 과정과 최종 과제 방향은 [ROADMAP.md](ROADMAP.md)에서 관리합니다.

## 채점 원칙

- 코드의 문법, 구조, 동작과 문제 요구사항 충족 여부를 중심으로 채점합니다.
- 채팅 또는 Markdown 복사 과정에서 생긴 특수 공백과 인코딩 흔적은 실제 코드의 논리가 명확하면 감점하지 않습니다.
- 보안 문제에서는 정상 동작뿐 아니라 접근 제어, 실패 조건과 공격 가능성도 함께 확인합니다.
